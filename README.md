# Index of Unencoded Scripts

A one-page vertical scroll of frames A–I from the Figma file *VTC-MCP-Test*.
Live at https://silktabrizrug.github.io/indexoftheunencoded/

To update a frame, re-export it from Figma as `frames/<Letter>.webp`. To add a new frame, also add one line to `FRAMES` in `index.html`.

Hovering a glyph or its number enlarges the glyph and turns the number red (spec: Figma frame "ON HOVER EXAMPLE"). Glyph positions live in `glyphs.js`.
